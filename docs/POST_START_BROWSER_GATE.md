# Post-start browser regression boundary

A real authenticated browser session exposed a delayed hang shortly after `Start New Game`. The failure reproduced in both `legacy` and `parity`, which ruled out Cloudflare Access, OTP, ULS entitlement handling, and Gateway parity as the cause.

The original startup path eagerly constructed the Adaptive Tutor core during ordinary game startup. That construction activated Tutor extensions even though Tutor mode had not been requested. Isolation then showed that the core constructor itself was bounded; the actual main-thread seizure came from Tutor DOM observers activated by that eager path. In particular, Level Progression observed the Tutor subtree and rewrote its own progress markup on every callback, creating a MutationObserver feedback loop. Strategy Orientation had the same class of latent self-trigger risk because it removed and recreated its own observed card on each render. Both renderers are now idempotent and ignore/avoid self-generated mutations.

The production boundary is explicit: ordinary Cancellation Hearts startup may load Tutor capability code and pre-register Tutor extension sources, but it must not construct the real Adaptive Coach core. The core is constructed exactly once only when the user explicitly enters Tutor mode. Tutor extensions install at that same initialization boundary, after the core exists, and repeated Tutor starts reuse the existing core.

The real-browser gate protects both sides of the boundary. For `legacy` and `parity`, it starts a normal eight-player game, waits through the former crash window, verifies the page remains responsive, and asserts Tutor-core construction count remains zero. It separately enters Tutor through the real `gameMode`/`Start Tutor` control, verifies one real core construction, verifies the opening diagnostic is visible, and verifies a repeated Tutor start does not construct another core. In parity mode the local harness returns an explicit authorization denial for Gateway calls so fail-closed learning-service behavior is also proven not to crash gameplay.
